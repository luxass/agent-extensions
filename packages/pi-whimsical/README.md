# @luxass/pi-whimsical

Give [Pi](https://github.com/badlogic/pi-mono) a rotating set of playful working messages: coding jokes, fantasy, memes, and a few Star Wars references.

## Install

```sh
pi install npm:@luxass/pi-whimsical
```

When Pi starts a turn, the extension picks a message to display while the agent works. It clears the message when the turn ends. There are no commands or settings.
